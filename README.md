# Project FORESIGHT — Demand & Inventory Intelligence

**Zidio Development · Data Science & Analytics · Client scenario: NorthBay Living**

FORESIGHT is an end-to-end demand forecasting and inventory decision-support prototype. It converts daily sales, SKU master, calendar and inventory extracts into SKU-level forecasts, stockout/overstock risk scores, rupee impact estimates, and an interactive planning dashboard.

> **Data note:** The Zidio brief states that four simulated client extracts should accompany the engagement. Those raw files were not available in the provided dashboard materials, so this repository uses a **schema-compatible synthetic development dataset** generated by `generate_data.py`. Results in this repository are therefore **prototype/demo results, not NorthBay Living production results**.

## What is included

- **D1:** data cleaning, merge and leakage-safe feature engineering
- **D2:** data-quality log + EDA insight memo
- **D3:** 8-week SKU-level forecasting, seasonal-naive baseline and rolling-origin backtest
- **D4:** stockout/overstock risk scoring, actions and rupee impact
- **D5:** Streamlit planning dashboard
- **D6:** FastAPI scoring service
- **D7:** executive readout
- Reproducible notebooks and setup instructions

## Data schema

| Extract | Key fields |
|---|---|
| `sales_daily` | date, sku_id, units_sold, revenue, unit_price, promo_flag |
| `sku_master` | sku_id, category, subcategory, launch_date, unit_cost, list_price |
| `calendar` | date, week, month, season, is_holiday, promo_event |
| `inventory_snapshots` | date, sku_id, on_hand_units, on_order_units, lead_time_days, reorder_point |

## Forecast evaluation

The model is evaluated with **rolling-origin time-series backtesting**, not a random train/test split.

Current run:

| Metric | WAPE |
|---|---:|
| Seasonal-naive baseline | **0.236** |
| LightGBM model | **0.199** |

|      1 | 2024-12-31    |          0.252  |       0.2116 | True                   |

The model beats the baseline in all four backtest folds in the current reproducible run.

## Inventory decisioning

The risk layer uses transparent, adjustable rules:

- Stockout risk compares lead-time demand × 1.2 safety margin against on-hand + on-order inventory.
- Overstock risk compares on-hand inventory with the 8-week forecast demand.
- Scores are mapped to `Reorder Now`, `Markdown / Clear`, `Watch / Volatile`, or `Healthy`.
- Rupee impact is shown separately as sales at risk and capital locked.

Current prototype run across 200 SKUs:

- **Sales at risk from stockouts:** ₹4,184,505
- **Capital locked in overstock:** ₹5,835,882
- **Total value at stake:** ₹10,020,387
- **Reorder now:** 1
- **Markdown / clear:** 5
- **Healthy:** 194

These figures are **synthetic-demo estimates**, not client financial forecasts.

## EDA highlights

The current synthetic development data shows:

1. Promotional weeks have about **73% higher average weekly unit demand** than non-promo weeks.
2. Demand is concentrated among a small group of top-moving SKUs, making stockout protection economically important.
3. Some SKUs show pronounced recent demand declines, supporting targeted markdown review.
4. Seasonal/category patterns justify calendar-aware forecasting features.

See `reports/eda_memo.pdf` for the detailed memo.

## Limitations

- Synthetic data is used because the expected client extracts were not supplied with the available materials.
- The forecast interval is a **planning band**, not a calibrated statistical confidence interval.
- No live ERP/WMS integration, supplier selection, price optimisation, streaming data or automated purchase-order placement is included.
