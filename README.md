# PROJECT FORESIGHT — AI-POWERED DEMAND & INVENTORY INTELLIGENCE PLATFORM

**Zidio Development · Data Science & Analytics**  
**Client Scenario:** NorthBay Living

FORESIGHT is an end-to-end demand forecasting and inventory decision-support prototype designed to transform sales, SKU, calendar, and inventory data into actionable planning insights.

The platform provides:

- SKU-level demand forecasting
- Stockout and overstock risk scoring
- Inventory action recommendations
- Rupee-based business impact estimates
- Interactive Streamlit planning dashboard
- FastAPI scoring service
- Executive-level reporting

> **Data Note:** The Zidio project brief specifies four simulated client extracts that should accompany the engagement. These raw extracts were not available in the provided dashboard materials. Therefore, this repository uses a **schema-compatible synthetic development dataset** generated by `generate_data.py`. All reported metrics and financial estimates are **prototype/demo results and should not be interpreted as NorthBay Living production results.**

---

## PROJECT OBJECTIVES

FORESIGHT is designed to answer key inventory-planning questions:

1. What demand should be expected for each SKU over the next eight weeks?
2. Which SKUs are at risk of stockout?
3. Which SKUs may be carrying excessive inventory?
4. Which inventory actions should be prioritized?
5. What is the estimated financial value at risk?

## FORECASTING APPROACH

The forecasting pipeline produces an **8-week SKU-level demand forecast**.

Model performance is evaluated using **rolling-origin time-series backtesting**, rather than a random train/test split.

### Overall Performance

| Model | WAPE |
|---|---:|
| Seasonal-Naive Baseline | **0.236** |
| LightGBM Model | **0.199** |

**Lower WAPE indicates better forecasting performance.**

### Rolling-Origin Backtest

| Fold | Cutoff Week | Baseline WAPE | Model WAPE | Model Beats Baseline |
|---:|---|---:|---:|:---:|
| 1 | 2024-12-31 | 0.2520 | **0.2116** | Yes |
| 2 | 2025-03-18 | 0.2304 | **0.2074** | Yes |
| 3 | 2025-06-03 | 0.2224 | **0.1983** | Yes |
| 4 | 2025-08-19 | 0.2406 | **0.1781** | Yes |

The LightGBM model outperforms the seasonal-naive baseline across all four backtest folds in the current reproducible run.

## INVENTORY DECISION INTELLIGENCE

The risk layer uses transparent and adjustable business rules.

### Stockout Risk

Lead-time demand is compared against available inventory using a **1.2× safety margin**.

### Overstock Risk

On-hand inventory is compared against projected **8-week forecast demand**.

### Decision Categories

- **Reorder Now**
- **Markdown / Clear**
- **Watch / Volatile**
- **Healthy**

### Current Prototype Results

The current prototype run covers **200 SKUs**:

| Indicator | Result |
|---|---:|
| Sales at risk from stockouts | **₹4,184,505** |
| Capital locked in overstock | **₹5,835,882** |
| Total value at stake | **₹10,020,387** |
| Reorder Now | **1 SKU** |
| Markdown / Clear | **5 SKUs** |
| Healthy | **194 SKUs** |

> **Important:** These financial figures are **synthetic-demo estimates**, not client financial forecasts.

## EDA HIGHLIGHTS

The current synthetic development dataset indicates:

1. Promotional weeks show approximately **73% higher average weekly unit demand** than non-promotional weeks.
2. Demand is concentrated among a relatively small group of top-moving SKUs.
3. Some SKUs show pronounced recent demand declines, supporting targeted markdown review.
4. Seasonal and category-level patterns support the use of calendar-aware forecasting features.

## LIMITATIONS

- The project uses synthetic development data because the expected client extracts were not supplied with the available materials.
- Forecast intervals represent **planning bands**, not calibrated statistical confidence intervals.
- Live ERP/WMS integration is not included.
- Supplier selection and procurement optimization are outside the current scope.
- Price optimization is not implemented.
- Streaming/real-time data ingestion is not included.
- Automated purchase-order creation or placement is not included.

---

## CONCLUSION

FORESIGHT demonstrates an end-to-end approach to demand forecasting and inventory intelligence by combining machine-learning forecasting, time-series evaluation, transparent inventory risk rules, financial impact estimation, and interactive decision support.

The prototype provides planners with a practical view of **expected demand, inventory risk, and prioritized actions** to support better inventory decisions.
